 codex
v2 预览（当前版本）
https://codex.longnankejia-dev.pages.dev/
对应 codex 分支的 v2。未注入 API Key，问答与语音输入会提示未配置；3D 模型、地图与典藏可直接体验。

v2 这一轮改动在 codex 分支。它从 main 基线 eab8f30 开始，基线标签为 v2-base。 codex 分支的固定预览地址是 https://codex.longnankejia-dev.pages.dev/；v2 是版本号。

四个可点地址分别是正式版 main、独立工作的 qcode、dev，以及 codex 上的 v2 预览。codex 地址部署后会随 codex 分支更新。

本地那份和线上这份不是一回事。双击 qidong.bat 打开的是这个文件夹当前检出的分支， 它要 push 并且部署过，线上才会变。启动脚本会打印 branch 名字 @ commit， 想知道自己在看哪一份就看那一行。

要不要加速器？不需要。*.pages.dev 这些地址实测可直连； 手机用移动网络也能打开。

要扫码的场合：任意一个页面顶栏「扫码访问」会把当前地址画成二维码，馆内观众扫它即可。
