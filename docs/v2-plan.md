## 协作边界

三个 Luna 子代理分别负责 3D、地图、知识库；文件所有权分开。主代理负责版本信息、模块集成、验证脚本、浏览器截图检查、问题反馈与最终交付。

## 验收标准

1. 静态完整性与语法检查通过。
2. 原有浏览器套件的实质回归通过；需求变更影响旧断言时，解释原因并保留有意义的保护。
3. 新问答测试证明相似/差异回答不同，且确实回应问句；茶果未导入。
4. 地图在手机/桌面缩放后仍可定位、点选、重置；拖拽不触发点选；出处没有新造。
5. 两件重点3D模型检查实际截图、正背面、近景与手机取景，几何细节增加不能导致不可用的绘制负担。
6. 记录来源、实物参考和模型局限。展示模型不宣称测绘级复原。

不自动改动 main；公网部署状态以实际部署结果为准。
