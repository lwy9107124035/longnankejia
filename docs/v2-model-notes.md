# v2 七件三维模型说明与证据边界

## 先看证据等级

七件模型都是 Three.js 程序化构建的交互展示模型。当前一轮按可核对的照片外观与公开文字资料调整形状、纹样和材质；**没有使用摄影测量、扫描网格或文物测绘图，也不能称为逼真到可作尺寸依据的复原**。着色、几何细节和光影用于提高屏幕展示的可读性，不能替代实物档案。缺少近照或文字佐证的部分，下面明确标作“概念/示意”。

## 关西新围

官方介绍给出的可引用总体信息是：建筑面积约 7426 平方米，方形“回”字布局，包含中央祠堂、四角炮楼，以及九幢、十八厅的建筑关系。本模型据此做方形围合、四角高塔、中央厅堂与天井的空间示意；**不是按 7426 平方米比例缩放，也不是逐幢逐厅的测绘复原**。

代码中可见的表现包括夯土/砖色分层墙体、收分墙面、方形角楼、双坡瓦面、门洞、垛口、内侧走道和中轴厅堂。程序化瓦、墙面与卵石贴图是渲染材质，不代表对实物瓦片、夯土配方、石纹或拼花的取样。为了让小屏幕能读清空间，模型采用简化几何和示意开口。

已知边界：实际门位与模型示意门洞不完全对应；模型只表现两处天井和中轴厅堂关系，没有复原全部建筑、房间、天井、门坪或半月池；具体垛口数、窗棂、脊饰和尺寸未经逐项资料核验。不要将截图或模型数值用于建筑测绘、施工或文保判断。

## 冬头帕织带

本版由两条垂挂的织带、黑色护额关系示意、可见的彩色经线细节、素色拧段、结头和散穗组成。纹样按 `微信图片_20260928193605_179_964.jpg` 的可见蓝紫红色带与白色几何装饰抽象绘制；图案中没有可确认的汉字或固定祝福含义，不应将其解释成照片中的原字样。

两条织带及护额如何对应、带子如何佩戴，只按展示可读性做概括，不由该照片单独证明。程序中展示宽度和长度是为了让纹样在手机视口中可见的屏幕比例，并非藏品实测尺寸；颜色分段、经线数量、拧法、流苏结构、织造工具和工艺术语均未凭该照片做精确还原。纹样是概念稿，不对应特定传承人或藏品。

## 其余器物的表达范围

- **虎头帽**：以展柜照片可见的多款颜色为参考，采用黑布体、额前抽象绣片和护耳形成可辨识的展示轮廓。照片没有清楚展示统一帽型或绣片近景，因此金边、固定五官、特定配饰和某一款定南童帽的断言均不成立。
- **蓝染布**：将照片中可见的靛蓝底色、几何折叠留白和圆形放射纹转为程序化纹样；布面褶皱与染缸只服务于展示情境。没有把纹样说成某个真实样布的复制，也没有从照片推定植物原料或配方。
- **客家凉帽**：竹编冠部、圆宽檐和垂布是易于理解的概念形体。本批资料缺少可确认的凉帽实物近照，因此没有证据支持精确帽檐比例、编织纹理、布色或褶数。
- **竹编浅圆器**：照片能看到浅口圆形竹器、交织底面与较厚圈口；本版以几何交错篾带表现“编织”关系。照片无法确认器名、用途、器身深度或技法，故代码与说明都按“浅圆器示意”理解，页面现用“簸箕”是面向观众的分类名。
- **客家米酒坛**：本批没有可信的米酒坛近照。当前旋转体、开口和棕色釉感是通用陶坛概念，不说明其为龙南地方典型，也不据此推断封口方式、酒类工艺或年代。

## 渲染、取景与验证

转台由相机俯角控制，模型自身只绕竖轴旋转，避免模型随地面一起倾斜而穿地。`SEAT_ADJUST` 按模型最低点把七件模型放到统一场景地面；默认取景根据画布宽高比调整距离，减少手机画面裁切。

`tests/v2_visual_review.mjs` 对七件模型生成桌面与手机视口截图，并核对实际渲染调用、顶点是否在视野内、绘制次数及三角面预算。该测试证明模型在当前页面中的渲染和取景表现，不证明历史形制、材料或尺寸真实性。若模型代码继续变化，应重跑视觉验收并人工核看截图。

```
node tests/v2_visual_review.mjs
```
