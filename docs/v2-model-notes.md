# v2 三维模型说明

## 关西新围

模型参照赣南龙南关西新围的长方形围合形制构建，避免套用福建圆形土楼外观。按资料落实的构件：

- **收分围墙**：三层围墙，底厚与顶厚按"围墙高9米、底部厚2米、顶部厚1米"的比例做成 2:1 的棱台，不是等宽方盒；下段三合土夯土、上段青砖包砌（"金包银"外砖内土），接缝一道石腰线。
- **墙顶**：女墙、一排垛口与内侧走马廊石板（资料称顶层环形夹墙走廊为"外走马"）。
- **四角炮楼**：方形、高过围墙一层，下圈四撇水腰檐、上承两坡瓦顶与山墙，即资料所述"两层歇山式屋顶"。
- **屋顶**：硬山搁檩小青瓦两波顶，实例瓦片按坡面排布，檐口加一排瓦当。**没有加马头墙**——资料指出龙南属桃江流域，马头山墙在该流域数量较少。
- **门**：石框、门楣、门槛、木门，加门簪与门枕外的抱鼓石。
- **院内**：三进厅堂（前厅、中厅、后祠堂）、两处天井与檐廊列柱，祠堂最高并带脊饰。天井地面用拼花卵石贴图（铜钱纹与万字纹），取自资料"天井、门坪常用鹅卵石或砖块拼砌出铜钱纹、万字纹、寿字纹"。
- 枪眼按"下密上疏"分三层排布，`InstancedMesh` 批处理。

### 门前禾坪与半月池：试过，暂未放入

资料明确关西新围门前有禾坪、东大门前有半月池。这一轮把二者按抬高、贴地、内嵌、收紧四种摆法都做过，在 320px 高的视口与默认俯角下始终读成"悬在台面外的一块板"，反而破坏整体可信度，因此先不放进模型。要恢复必须同时改场景地面半径（现为 5）或默认俯角，并接受围屋在画面里更小。

### 已知偏差（不是测绘复原）

- 关西新围**不设正大门，仅东、西两座侧门**，半月池在东大门正前。本模型仍是前二后一的门位、池子放在正面中轴前，围向与门的对应关系不严格。
- 资料记院内**14 个天井**（一说 11 个），模型只做了中轴两处天井与三进厅堂的空间关系，未复原全部天井与房间数（每层 79 间 / 总数 282 间的说法本身互相冲突）。
- 垛口数量、女墙高度、瓦当滴水与脊饰样式在关西新围的公开资料中**未证实**，按赣南围屋常见做法示意。
- 枪眼"外小内大呈葫芦形"未做到，仍是矩形孔洞实例。
- 长宽比取 3.5×2.6（约 1.35:1），实地约 94.75×83.36（1.13:1），未对齐。

## 冬头帕织带

展示对象是冬头帕：黑色双层护额，两端各垂一条手织丝带（"花带缝于头帕两端、位于额前上方"）。上一版用柱架/绕线杆承托，改按佩戴状态呈现。

- **架线顺序**按资料与龙南政府页逐字一致：中间至少 11 根白线，两边依次红 5、蓝 2、绿 2、黑 2。贴图与近景的经线细丝用同一份顺序，`tests/v2_models.test.mjs` 把顺序和根数钉住。
- **分段**：织花段 → 亚带 → 结头 → 流苏。亚带按"先留10厘米以上流苏，用五彩线织成约15厘米的亚带"表现为流苏与图样之间的素色段，几何上是截面绕垂轴旋转（拧），不是把带子压扁。
- **纹样**：白芯上是万字纹（十字加回钩）与菱形，红带上是锯齿菱格挑花。
- **丝光**：roughness 约 0.42，低高光而非缎面。
- 经线细丝并入单个 `BufferGeometry`，流苏用 `InstancedMesh`，重复构件不逐根增加 draw call。

### 已知偏差

- 成品**宽约 2cm、长约 67cm**（33:1）。展示时放大到约 3.5cm×58cm（约 17:1）：在 320px 高的视口里，2cm 宽的带子会把挑花纹样压成一条线，看不出技艺。比例是刻意为之的让步。
- 两根带子的下垂方向、是否平行或扇开，公开资料未记载，按"自发际两侧平贴下垂"处理。
- "亚带"在公共文献里只有复述、没有定义，此处按素色五彩段推测表现。
- 流苏末端打结或编辫的细节未证实，做成散开的经线穗加一个结头。
- 纹样"只出现在中央白地"没有出处，带宽仅 2cm 时纹样本应满幅循环；现在的白芯万字加红带菱格是编排，不声称复制某位传承人的织样。

## 渲染与取景

转台是**相机绕俯角**，不是把模型扳斜：`animate()` 早先写的是 `currentModel.rotation.x = rotX`，等于把模型连地面一起向前扳 0.44 弧度，围屋前缘因此扎进地板 0.9 深、后缘浮起，看起来就是"与底面穿模"。现在模型只绕自身竖轴旋转，俯仰由相机完成。

直立之后暴露出各件自定 `position.y` 的历史遗留：簸箕悬空 1.15、虎头帽 1.05、凉帽 0.95、米酒坛 0.57、蓝染的染缸几乎埋进地里。`SEAT_ADJUST` 按逐实例逐顶点量出的 trueMinY 把七件统一坐到地面（-1.15），焦点同步下移同样的量，因此逐项调好的取景距离与画面关系不变。

围屋基座底面与场景地面齐平，默认俯角 0.44 弧度、取景距离 8.2；织带取景距离 3.15，护额与流苏两端都在画面内。默认取景按**画布宽高比**自动拉远（基准 1.28，最多 1.35 倍）：手机上的 3D 画布接近方形，水平视野更窄，写死一个距离会在手机上左右出框。`tests/v2_visual_review.mjs` 七件全截图（原先只截围屋与织带，另外五件从来没有可视证据），逐顶点检查默认视图完整（桌面 1280×1000 与手机 360×800，NDC 阈值 0.98），并核对渲染器确实提交了这一件的绘制（`calls` 与 `meshes` 同量级——模型忘了 `scene.add` 时逐顶点测量照样报"完整"），核对绘制次数与三角面预算（上限 300 次绘制、20 万面），并按未旋转的局部包围盒盯住围屋外轮廓的长宽比——收分系数一度被错乘到墙长上，把东西两墙拉到 5.2 长戳在围合之外，只有量外轮廓才能发现。

瓦与夯土改用程序化贴图（`qingwaRoof`、`rammedLoam`、`cobbleCourt`、`pondWater`）：原先直接乘 `assets/textures/` 里的 PNG，那两张图本身偏黑，整片屋顶会糊成炭黑、天井被吃掉。发布仍不引入任何外部图片，`tests/run_site_tests.mjs` 有对应断言。滚轮/双指缩放上限从 9 放宽到 12。
