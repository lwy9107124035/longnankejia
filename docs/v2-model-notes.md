# 本轮 12 件三维展品模型说明

## 原图对照画廊

每件展品下方的“实物参考”折叠区由 `js/model-references.js` 提供图片、视频和来源路径。点选图片或视频卡片可在弹层中查看大图或播放原视频；当前展品切换时，画廊内容也随之切换。蓝染样布的纹样控制与照片对照，可分别查看双环和放射纹样。

页面引用 `assets/model-references/` 中的展示副本；`original` 字段记录相应原始素材位置。`3D模型参考原图/`、`博物馆图片/` 和传承人资料目录中的源图、源视频保持原样，本轮没有改写或剪辑它们。视频抽帧仅作为人工查看参考，不能替代原视频证据。

## 关西新围的表达范围

`weiwu` 当前采用方形平面围合与较低的外围墙体，四角设置炮楼，并在围内以中央祠堂作为空间中心。屋面、墙色、院落和内部构件用于帮助观众理解总体关系。这个比例和内部排布属于展示示意，模型没有使用逐点测绘数据，也不声称精确复现关西新围的全部建筑、门位、房间或构造尺寸。

## 问答、地图与资料边界

地图保留上一版的缩放、平移、分类筛选和快捷地点选择；本轮重点修改模型与问答。

问答改为统一的主体识别、问题维度判断、分段检索、资料覆盖判断和连续对话。简单明确概述可直接读取资料，具体问题、比较与追问交给大模型整理，再独立核对证据编号、来源句及数值。缺少证据、接口失败或核对未通过时给相关资料节选和缺口说明，不编造补全答案。详见[问答工作流](qa-workflow.md)。

《非遗.docx》前三个主题分为工具、选材、工序、纹样及传习等可检索段落；茶果章节继续排除。用户下载的《客家传统纹样的文化意蕴及其实践价值.pdf》17页已提取并核读，正文整理为9个有页码的主题条目。缺失图片未补造，图12狮象与图13石狮以已有图片及图注核对。后台知识库导入保留主题、别名和来源。

本轮按用户授权合理补全照片未展示的三维结构，不把推定背面、体积和内部结构当作实物测量。12件模型均检查四个水平视角和手机默认视图；新增衣身/袋囊正反面射线、开口、脖围薄布及纸花纵深回归。最新验证记录见[逐条需求核对](v3-requirements-audit.md)。
