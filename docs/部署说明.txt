龙南客家非遗数字助手 — 部署指南
==================================

当前方案：Git 推送 → Netlify 自动部署
（已删除 zip 手动打包方式）

首次配置（只需一次）
--------------------
1. 打开 https://app.netlify.com
2. 选择你的站点 → Site configuration → Build & deploy
3. 点 "Link site to a Git repository"
4. 选 GitHub → 授权 → 选择仓库 longnankejia
5. 构建设置（netlify.toml 已配好，一般不用改）：
     Build command:  echo 'window.APP_SECRETS={apiKey:"'$SILICONFLOW_API_KEY'"};' > js/secrets.js
     Publish directory:  .
6. 左侧 Environment variables → Add variable：
     Key:    SILICONFLOW_API_KEY
     Value:  你的硅基流动 API Key
7. 保存后回到 Deploys → Trigger deploy → Deploy site

日常更新（全自动）
------------------
  git add -A
  git commit -m "改了什么"
  git push

push 完 Netlify 自动重新部署，网址不变，约 30 秒生效。

本地预览
--------
  双击 qidong.bat（手机与电脑同一 Wi-Fi 可扫码）
  双击 zhanting.bat（停止服务）

API Key 安全说明
----------------
  Key 存在两处（都不在代码里）：
  - Netlify 环境变量（Settings → Environment variables）
  - GitHub Secrets（如果也开了 GitHub Pages）
  构建时自动注入到 js/secrets.js，该文件在 .gitignore 中。

管理知识库 / API 配置
---------------------
  用户页面底部 → 「⚙ 管理入口」→ 密码登录（默认 admin123）
  可增删改知识条目、切换 AI 引擎、修改模型参数。
  修改存在浏览器 localStorage，不影响源码。
