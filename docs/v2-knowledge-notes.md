# v2 知识入库与问答意图说明

此轮把蓝染、客家织带、杨村竹编、南通蓝印花布、大理白族扎染及客家传统纹样资料加入本地知识库。资料来源附在对应条目和可见答案末尾；比较答案只引用有明确来源的地域样本。未配置 API 或 API 故障时，蓝染比较、复合工艺、工艺流程和传承人问法仍由本地意图路由返回针对答案。

## 使用的资料

- 甲方提供的《非遗.docx》提取文本：织带、竹编、蓝染三个部分。文本里的黄竹英年龄分别出现 76 岁、78 岁，因此不收录年龄；传承人级别只作为材料中的说法呈现，并说明未在本次工作中独立核验。蓝染项目是否以独立名称列入龙南县级以上名录，材料没有给出可核验结论，所以答案明确保留不确定性。
- “源·创丨客家传统纹样的文化意蕴及其实践价值”，微信文章，https://mp.weixin.qq.com/s/BiGOrDhf8m18BvCl-lRLsA 。已通过页面正文读取。文章讨论建筑、服饰、器物、民俗用品上的客家纹样以及吉祥寓意、族群和生活语境；仅作为纹样背景，不据此推断某一条龙南织带纹样的具体出处。
- 中国非物质文化遗产网，“南通蓝印花布印染技艺”，https://www.ihchina.cn/project_details/14296/ 。用于项目名录和南通工艺概述。
- 江苏省文化和旅游厅，“江苏南通蓝印花布印染技艺是首批国家级‘非遗’”，https://ydyl.jiangsu.gov.cn/art/2022/3/29/art_76472_10395005.html 。用于蓝白棉布、历史与地方工艺背景。
- 南通史志网，“二甲蓝印花布”，https://www.ntszw.gov.cn/?a=show&c=index&id=1226 。用于刻花版和防染剂等地方工序细节。
- 大理市人民政府，“国家级非物质文化遗产之——大理白族扎染”，https://www.yndali.gov.cn/dlsrmzf/c103383/pc/content/1981555743835394048/content_1981555743835394048.html 。用于扎缝、浸染、拆线和植物蓝靛等对照内容。

## 回答边界

“其他地方蓝染”没有一个可由这些材料概括的统一工艺。未指明地区时，助手会将南通蓝印花布与大理白族扎染作为两个有出处的参照，并提示它们只是样本。相似问题先回答可追溯的共同点；区别问题先解释防染、纹样和工序路径差别。客家蓝染来源没有覆盖的细节会标成资料未说明。

茶果部分未入库。织带与竹编并问时先走比较意图，避免由“编织”等共享字词触发任一单主题介绍。管理员对原有条目（包括 `landye`）的本地覆盖路径保持原样；问答引擎仍从 `Store.getEntries()` 读取合并后的条目。
