# 视频上传与播放

100～500 MB 的视频先上传到老师自己使用的视频平台，发布后关联到本站。本站不限定平台，也不需要开通 R2 或填写支付信息。

1. 在所用视频平台上传视频，完成发布或审核，确认其他人也能观看。
2. 复制视频播放地址。优先使用完整视频链接，或平台提供的嵌入播放器地址。
3. 打开本站「管理入口」，在「科普」中编辑对应围屋资料，把地址粘贴到「讲解视频」后保存。方言条目请先选择「视频影像」类型，再在音视频地址栏填写链接。
4. 回到对应围屋资料，点击播放视频讲解。手机端如遇平台限制，点击「打开原播放页面」。

哔哩哔哩只是可选示例：支持完整链接、BV 号和 b23.tv 短链，也能从包含文字的分享内容中取出链接。腾讯视频、优酷、YouTube、Vimeo 的常见视频链接会转换成对应播放器；其他平台可填写其 HTTPS 嵌入播放器地址。

已有视频文件地址也可直接填写，支持 MP4、WebM 等浏览器可解码的格式，以及 HLS（m3u8）和 DASH（mpd）视频流；没有文件扩展名的直链也会尝试播放。MP4 采用 H.264 视频和 AAC 音频时，手机与电脑的兼容性通常较好。

注意：普通百科页面、网盘分享页、私密或需登录的页面，不一定能作为站内视频源；平台也可能禁止站外播放。播放器会保留原页面入口。视频流来源还需允许跨站访问。把电脑或手机里的文件名填入地址栏不会上传文件。

播放器使用 [Shaka Player 5.3.4](https://github.com/shaka-project/shaka-player/releases/tag/v5.3.4) 处理浏览器不原生支持的 HLS/DASH，仅在需要时加载；许可证保留在 `js/vendor/shaka-player.LICENSE`。
