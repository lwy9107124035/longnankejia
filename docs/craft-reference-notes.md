# 四件手工艺模型：原图依据与表达范围

`js/models-crafts.js` 提供 `window.CraftModels.build(id, THREE, textures)`，支持 `zhiji`（木织机）、`zhiyi`（纸艺花树）、`boji`（圆竹筛）和 `liangmao`（竹编斗笠）。每个模型把来源编号写入 `userData.referenceIds`，并标记 `userData.referenceMode = 'reference-shaped'`。这些是按可见照片形体制作的程序模型，不是扫描、测绘或工艺复刻；照片无法证明的尺寸、材料细节和制作步骤不作实物断言。

## 木织机（`zhiji`）

主要依据：`3D模型参考原图/织机/微信图片_20260928203759_226_964.jpg`（编号 226）展示一架带蓝白经线和垂布的木机，能直接看到方木机架、低部框架、斜撑、横梁、前侧织口、织物悬垂和前伸坐凳。`.cache/craft-review-frames/27296ff84274847bd5f562ce2c7cfbe5.jpg` 是视频 `27296ff84274847bd5f562ce2c7cfbe5.mp4` 的多视角帧，补充了机架后侧与整体纵深；`.cache/craft-review-frames/bafb8f6dc8b1a21e940d037804dcf945.jpg` 对应 `bafb8f6dc8b1a21e940d037804dcf945.mp4`，展示多架织机、织带及局部构件。模型参考编号记为 `[226]`。

模型保留四腿低框、两侧高架与斜撑、横梁和卷布轴、细白筘线、连续蓝白布面、前伸坐板、脚踏板及梭子等照片中可辨部件。布面沿上方后梁、织口到前侧垂布连续弯折，纹理裁自 226 中的实物蓝白条纹布；坐板扩为横跨前侧框架的宽板，由延长底梁承托。经纬丝线密度、脚踏连接方法、梭子形式和各木构件的准确装配关系无法仅凭照片与走拍视频完全确认；本模型对遮挡部位作了简化，尺寸比例也只是便于展示的估计。

## 橙色纸花盆景（`zhiyi`）

依据：`3D模型参考原图/客家纸艺/微信图片_20260928203736_204_964.jpg`、`..._206_964.jpg`、`..._207_964.jpg`（编号 204、206、207），以及视频 `3e1b1cb991c8931d279b2dd15f6bbdd8.mp4`（检查帧见 `.cache/craft-review-frames/3e1b1cb991c8931d279b2dd15f6bbdd8.jpg`）。多张照片和视频显示同一件橙色花树状纸艺：粗壮弯曲的棕色树干，向上及两侧分枝，枝梢有橙色花簇和少量叶芽；树干种在深绿、六边形外观的盆中，盆面铺浅色石粒。模型来源编号为 `[204, 206, 207]`。

模型按 204 的正面轮廓修正树干：从盆口向左低回，再向右上方伸展，并保留下部横枝、右侧弯枝及疏密不均的细枝。花簇由三层带中央折痕、上翘边缘的薄片花瓣组成，替换球状花瓣；共 48 个概括花位，位置与数量不作为实物逐朵计数。盆的正面及左右两块可见绘饰、树皮小块表面取自 204；未见背面保持深色。另有少量橄榄色芽叶、六边盆沿和浅色铺石。照片不能证明纸张折法、枝干骨架、纸材种类或盆体尺寸，几何折痕仅表达可见外观。

## 圆竹筛（`boji`）

依据：`3D模型参考原图/竹编/微信图片_20260928203842_244_964.jpg` 和 `..._243_964.jpg`（编号 244、243）。244 中前景可见一件大型浅圆竹器，边缘有较厚的卷边，底部以斜向篾片密织；同画面也出现其他篮盘，无法从照片标签确认该器物的准确名称或用途。243 提供同组竹器展示的对照。模型来源编号为 `[243, 244]`。

模型表现浅圆盘形、低侧壁、双向斜编底面和圆形加固边。照片支持这些外观关系；无法可靠确认器物是否为筛、具体尺寸、编织起点、篾片截面与真实上下压篾次序。交错纹理用于展示“透空的竹篾编织”观感，不能当作精确工艺图。

## 竹编斗笠（`liangmao`）

依据：`3D模型参考原图/竹编/微信图片_20260928203842_249_964.jpg`（编号 249）。画面显示两件挂置的竹编锥形物：一大一小，底口开放，细竹篾形成疏密可见的交错菱格/六角孔网，边缘有较厚的收口；大件上可见红色线绳。模型来源编号为 `[249]`。

模型选取照片右侧较大的那件，表现为单只底部敞开的锥形篾编帽体；两组相交斜篾形成开孔格网，并加口沿和少量红绳。照片的视角、遮挡和分辨率不足以确认其确切用途、锥顶收法、完整编织走向、竹材处理、佩戴方式或尺寸。因此页面称“竹编斗笠”是当前展示分类，模型保留照片所见的开放锥形编织轮廓，不附加照片不支持的黑色围布、冠衬或帽带细节。

## 绘制方式与使用限制

重复的花瓣及织机筘线采用实例网格，竹筛篾片使用合并几何；场景模型以语义名称标注可辨部分。`scripts/build_craft_textures.py` 记录原图裁片及透视校正坐标，生成 `assets/model-textures/craft-*.jpg`，源图保持原样。程序几何、颜色和重复细节用于交互展示，不能据此测量尺寸、判定工艺流派或作为修复施工依据。若后续获得藏品档案、正交拍摄或可靠工艺记录，应据此修正目前无法确认的构件和编织关系。
